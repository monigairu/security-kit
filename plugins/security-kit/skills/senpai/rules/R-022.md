# R-022 パストラバーサル

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-22 パストラバーサル、OWASP Top 10:2025 A01 アクセス制御の不備 |

## 伝え方

- 何が危ないか: 入力された値を使って、ファイルの場所を組み立てている
- なぜ危ないか: 「../」などを使って、想定していない場所のファイルを読まれたり書き換えられたりする
- どう直すか: 実際の場所（リンクをたどった後）を求めてから、許可したフォルダの中にあることを確認する

## 違反例（指摘される書き方）

`app/files.py`

```python
def read_upload(name):
    with open(os.path.join(UPLOAD_DIR, name), "rb") as f:
        return f.read()
```

## 正常例（安全な書き方）

`app/files.py`

```python
def read_upload(name):
    base = os.path.realpath(UPLOAD_DIR)
    path = os.path.realpath(os.path.join(base, name))
    if os.path.commonpath([base, path]) != base:
        raise ValueError("許可していない場所")
    with open(path, "rb") as f:
        return f.read()
```

- ルールそのものを一時的に外すときは、プロジェクトの `.claude/security-kit.json` に期限つきの例外を書き、PR で承認を受ける。
