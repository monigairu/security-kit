# R-027 認証の不備

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | API |
| 根拠 | CWE-287 認証の不備、CWE-330 予測できる乱数の使用、OWASP Top 10:2025 A07 認証の失敗 |

## 伝え方

- 何が危ないか: ログインや本人確認の処理に、すり抜けられる弱点がある
- なぜ危ないか: 他人になりすまされたり、ログインなしで使われたりする
- どう直すか: フレームワークの認証の仕組みを使う。トークンには安全な乱数を使い、パスワードは専用の方式で保存する

## 違反例（指摘される書き方）

`app/reset.py`

```python
import random

def new_reset_token():
    return str(random.randint(100000, 999999))
```

## 正常例（安全な書き方）

`app/reset.py`

```python
import secrets

def new_reset_token():
    return secrets.token_urlsafe(32)
```
