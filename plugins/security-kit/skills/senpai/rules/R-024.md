# R-024 サーバーからの意図しない通信（SSRF）

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | API |
| 根拠 | CWE-918 サーバーからの意図しない通信（SSRF）、OWASP Top 10:2025 A01 アクセス制御の不備 |

## 伝え方

- 何が危ないか: 入力された値を、サーバーからの通信の宛先に使っている
- なぜ危ないか: 社内のシステムやクラウドの管理用の窓口に、サーバー経由でアクセスされる
- どう直すか: 宛先を許可リストで確認する。確認には、URL を解釈した後のホスト名を使う

## 違反例（指摘される書き方）

`app/preview.py`

```python
@app.post("/preview")
def preview(url: str):
    return requests.get(url, timeout=5).text
```

## 正常例（安全な書き方）

`app/preview.py`

```python
ALLOWED_HOSTS = {"api.example.com"}

@app.post("/preview")
def preview(url: str):
    parsed = urllib.parse.urlsplit(url)
    if parsed.scheme != "https" or parsed.hostname not in ALLOWED_HOSTS:
        raise HTTPException(status_code=400)
    return requests.get(url, timeout=5, allow_redirects=False).text
```
