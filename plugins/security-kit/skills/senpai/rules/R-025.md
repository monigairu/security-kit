# R-025 オープンリダイレクト

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-601 オープンリダイレクト、OWASP Top 10:2025 A01 アクセス制御の不備 |

## 伝え方

- 何が危ないか: 入力された値を、そのままリダイレクト先に使っている
- なぜ危ないか: 正規のサイトの URL から、偽のサイトへ誘導される
- どう直すか: サイト内の場所（/ で始まり、// で始まらない）だけを許可する。フレームワークの安全な機能を使う

## 違反例（指摘される書き方）

`app/login.py`

```python
@app.get("/login/done")
def login_done():
    return redirect(request.args.get("next", "/"))
```

## 正常例（安全な書き方）

`app/login.py`

```python
@app.get("/login/done")
def login_done():
    target = request.args.get("next", "/")
    if not target.startswith("/") or target.startswith("//") or "\\" in target:
        target = "/"
    return redirect(target)
```
