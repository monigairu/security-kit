# R-016 通信相手の確認を無効にしている

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-295 証明書の検証の不備 |

## 伝え方

- 何が危ないか: HTTPS の証明書の検証を無効にしている（verify=False）
- なぜ危ないか: 通信を途中で盗み見られたり、書き換えられたりしても気づけない
- どう直すか: 証明書の検証を有効のままにする。社内の証明書を使う場合は、その証明書を指定する

## 違反例（指摘される書き方）

`app/client.py`

```python
import requests

def fetch(url):
    return requests.get(url, verify=False, timeout=10)
```

`web/client.js`

```javascript
const agent = new https.Agent({ rejectUnauthorized: false });
```

`cmd/client.go`

```go
cfg := &tls.Config{InsecureSkipVerify: true}
```

## 正常例（安全な書き方）

`app/client.py`：社内の証明書を指定する

```python
import requests

def fetch(url):
    return requests.get(url, verify="certs/company-ca.pem", timeout=10)
```

`web/client.js`

```javascript
const agent = new https.Agent({ ca: fs.readFileSync("certs/company-ca.pem") });
```

`cmd/client.go`

```go
cfg := &tls.Config{RootCAs: pool}
```
