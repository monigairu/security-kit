# R-013 OS コマンドインジェクション

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-78 OS コマンドインジェクション、OWASP Top 10:2025 A05 インジェクション |

## 伝え方

- 何が危ないか: シェルを通してコマンドを実行している
- なぜ危ないか: 入力された値がコマンドの一部として解釈され、任意のコマンドを実行される
- どう直すか: シェルを通さず、コマンドと引数をリストで渡す（shell=True を使わない）

## 違反例（指摘される書き方）

`app/image.py`

```python
import subprocess

def thumbnail(name):
    subprocess.run(f"convert {name} out.png", shell=True, check=True)
```

`web/image.js`

```javascript
const { exec } = require("child_process");

exec(`convert ${name} out.png`);
```

`cmd/image.go`

```go
cmd := exec.Command("sh", "-c", "convert "+name+" out.png")
```

## 正常例（安全な書き方）

`app/image.py`

```python
import subprocess

def thumbnail(name):
    subprocess.run(["convert", name, "out.png"], check=True)
```

`web/image.js`

```javascript
const { execFile } = require("child_process");

execFile("convert", [name, "out.png"]);
```

`cmd/image.go`

```go
cmd := exec.Command("convert", name, "out.png")
```
