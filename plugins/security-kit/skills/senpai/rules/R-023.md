# R-023 クロスサイトスクリプティング（XSS）

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-79 クロスサイトスクリプティング、OWASP Top 10:2025 A05 インジェクション |

## 伝え方

- 何が危ないか: 入力された値を、そのまま HTML として画面に出している
- なぜ危ないか: 利用者のブラウザで攻撃者のスクリプトが動き、ログイン情報を盗まれたり操作されたりする
- どう直すか: 文字として出力する方法（textContent など）を使う。HTML が必要なら、無害化のライブラリを通す

## 違反例（指摘される書き方）

`web/comment.js`

```javascript
el.innerHTML = comment.body;
```

`web/Comment.jsx`

```jsx
<div dangerouslySetInnerHTML={{ __html: comment.body }} />
```

## 正常例（安全な書き方）

`web/comment.js`

```javascript
el.textContent = comment.body;
```

`web/Comment.jsx`

```jsx
<div>{comment.body}</div>
```
