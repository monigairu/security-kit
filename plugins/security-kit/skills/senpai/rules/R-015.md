# R-015 文字列をコードとして実行している

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-95 文字列をコードとして実行、OWASP Top 10:2025 A05 インジェクション |

## 伝え方

- 何が危ないか: eval や exec で、文字列をコードとして実行している
- なぜ危ないか: 入力された値が含まれると、任意のコードを実行される
- どう直すか: eval・exec を使わない書き方にする。値の変換だけなら ast.literal_eval を使う

## 違反例（指摘される書き方）

`app/calc.py`

```python
def parse(text):
    return eval(text)
```

`web/calc.js`

```javascript
const value = eval(text);
```

## 正常例（安全な書き方）

`app/calc.py`

```python
import ast

def parse(text):
    return ast.literal_eval(text)
```

`web/calc.js`

```javascript
const value = JSON.parse(text);
```
