# R-026 秘密情報・個人情報の露出

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | データ |
| 根拠 | CWE-532 ログへの機密情報の出力、CWE-209 エラーメッセージによる情報の露出、CWE-598 URL の問い合わせ文字列での機密情報の送信 |

## 伝え方

- 何が危ないか: 秘密情報や個人情報を、ログ・URL・エラーの応答に出している
- なぜ危ないか: ログや履歴を見られる人に、鍵や個人情報が渡ってしまう
- どう直すか: ログやエラーには出さない。必要なら一部を伏せる。鍵を URL に入れない

## 違反例（指摘される書き方）

`app/auth.py`

```python
logger.info("login ok: email=%s token=%s", user.email, token)
```

## 正常例（安全な書き方）

`app/auth.py`

```python
logger.info("login ok: user_id=%s", user.id)
```

## 見つけ方

- AI レビュー（作業の区切り・コミットの直後）: 分類 `sensitive-data-exposure`

## 当てはまらないとき

- 簡易チェック・AI レビューの指摘: その行に `security-kit:allow` と理由を書く
- 印は、利用者が当てはまらないと判断したときだけ付ける。AI が自分の判断で付けてはいけない。印の追加は PR でレビューされる。
- ルールそのものを一時的に外すときは、プロジェクトの `.claude/security-kit.json` に期限つきの例外を書き、PR で承認を受ける。
