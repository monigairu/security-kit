# R-014 安全でないデータの読み込み

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | CWE-502 信頼できないデータの復元、OWASP Top 10:2025 A08 ソフトウェアとデータの整合性の不備 |

## 伝え方

- 何が危ないか: 読み込むだけでコードが実行されうる形式（pickle、安全でない YAML の読み込み）を使っている
- なぜ危ないか: 細工されたデータを読み込むと、任意のコードを実行される
- どう直すか: JSON など実行を伴わない形式を使う。YAML は安全な読み込み方（safe_load）を使う

## 違反例（指摘される書き方）

`app/load.py`

```python
import pickle

def load(data):
    return pickle.loads(data)
```

`app/conf.py`

```python
import yaml

def load(text):
    return yaml.load(text)
```

`app/model.py`

```python
import torch

def load(path):
    return torch.load(path)
```

## 正常例（安全な書き方）

`app/load.py`

```python
import json

def load(data):
    return json.loads(data)
```

`app/conf.py`

```python
import yaml

def load(text):
    return yaml.safe_load(text)
```

`app/model.py`

```python
import torch

def load(path):
    return torch.load(path, weights_only=True)
```
