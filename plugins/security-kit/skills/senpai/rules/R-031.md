# R-031 外部スクリプトの読み込み

| 項目 | 内容 |
|---|---|
| 重大度 | 助言 |
| 領域 | コード |
| 根拠 | CWE-829 信頼できない機能の取り込み、CWE-353 完全性の確認の欠如、OWASP Top 10:2025 A08 ソフトウェアとデータの整合性の不備 |

## 伝え方

- 何が危ないか: 外部のサイトのスクリプトを、内容の確認なしに読み込んでいる
- なぜ危ないか: 配布元が乗っ取られると、差し替えられたスクリプトが利用者のブラウザで動く
- どう直すか: integrity 属性（内容の確認用の値）と crossorigin 属性を付ける

## 違反例（指摘される書き方）

`web/index.html`

```html
<script src="https://cdn.example.com/chart.min.js"></script>
```

## 正常例（安全な書き方）

`web/index.html`：属性を複数の行に分けて書いた場合

```html
<script src="https://cdn.example.com/chart.min.js"
        integrity="sha384-（配布元が示す値）" crossorigin="anonymous"></script>
```

`web/app.html`：自分のサイトのスクリプト

```html
<script src="/static/app.js"></script>
```

> 簡易チェックは、タグが1行で閉じているときだけ見る。複数の行に分けたタグは、AI レビューと PR 時の検査に任せる

## 見つけ方

- キット独自の簡易チェック K-020（書いた直後。対象: `*.html`、`*.htm`、`*.vue`、`*.svelte`、`*.jsx`、`*.tsx`）

## 当てはまらないとき

- 簡易チェック・AI レビューの指摘: その行に `security-kit:allow` と理由を書く
- 印は、利用者が当てはまらないと判断したときだけ付ける。AI が自分の判断で付けてはいけない。印の追加は PR でレビューされる。
- ルールそのものを一時的に外すときは、プロジェクトの `.claude/security-kit.json` に期限つきの例外を書き、PR で承認を受ける。
