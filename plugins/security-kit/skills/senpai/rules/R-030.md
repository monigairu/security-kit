# R-030 その他の脆弱性（AI レビュー）

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | コード |
| 根拠 | AI レビューの手引き（plugins/security-kit/data/review_prompt.md） |

## 伝え方

- 何が危ないか: AI レビューが、分類に当てはまらない脆弱性の可能性を指摘した
- なぜ危ないか: 内容は下のメモを参照。攻撃に悪用できる可能性がある
- どう直すか: メモの内容を確かめ、当てはまる場合は修正する

> 分類に当てはまらない指摘の受け皿のため、例は無い

## 見つけ方

- AI レビュー（作業の区切り・コミットの直後）: 分類 `other`

## 当てはまらないとき

- 簡易チェック・AI レビューの指摘: その行に `security-kit:allow` と理由を書く
- 印は、利用者が当てはまらないと判断したときだけ付ける。AI が自分の判断で付けてはいけない。印の追加は PR でレビューされる。
- ルールそのものを一時的に外すときは、プロジェクトの `.claude/security-kit.json` に期限つきの例外を書き、PR で承認を受ける。
