# R-017 弱いハッシュ・暗号の使用

| 項目 | 内容 |
|---|---|
| 重大度 | 助言 |
| 領域 | コード |
| 根拠 | CWE-327 弱い暗号の使用、CWE-328 弱いハッシュの使用、OWASP Top 10:2025 A04 暗号化の失敗 |

## 伝え方

- 何が危ないか: MD5・SHA-1 などの弱いハッシュや、古い暗号の方式を使っている
- なぜ危ないか: パスワードの保存や暗号化に使うと、破られるおそれがある
- どう直すか: SHA-256 以上や AES-GCM などを使う。パスワードの保存には専用の方式（bcrypt、argon2 など）を使う

## 違反例（指摘される書き方）

`app/hash.py`

```python
import hashlib

def digest(data):
    return hashlib.md5(data).hexdigest()
```

`app/crypt.py`

```python
from Crypto.Cipher import AES

def cipher(key):
    return AES.new(key, AES.MODE_ECB)
```

`web/crypt.js`

```javascript
const cipher = crypto.createCipher("aes-128-ecb", key);
```

## 正常例（安全な書き方）

`app/hash.py`

```python
import hashlib

def digest(data):
    return hashlib.sha256(data).hexdigest()
```

`app/etag.py`：安全のためではない用途（キャッシュの目印など）だと明示する

```python
import hashlib

def etag(data):
    return hashlib.md5(data, usedforsecurity=False).hexdigest()
```

`app/crypt.py`

```python
from Crypto.Cipher import AES

def cipher(key):
    return AES.new(key, AES.MODE_GCM)
```

`web/crypt.js`

```javascript
const cipher = crypto.createCipheriv("aes-256-gcm", key, iv);
```
