# R-029 権限の与えすぎ

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | 構成ファイル |
| 根拠 | CWE-250 不要な権限での実行、OWASP Top 10 for LLM Applications 2025 LLM06 過剰な権限 |

## 伝え方

- 何が危ないか: 目的に対して広すぎる権限を与えている（IAM・RBAC の設定、AI エージェントの権限など）
- なぜ危ないか: 乗っ取られたときに、被害が必要以上に広がる
- どう直すか: 必要な操作と対象だけに絞る。AI エージェントに、確認なしで何でも実行できる設定を与えない

## 違反例（指摘される書き方）

`infra/policy.json`

```json
{
  "Statement": [{ "Effect": "Allow", "Action": "*", "Resource": "*" }]
}
```

## 正常例（安全な書き方）

`infra/policy.json`

```json
{
  "Statement": [{ "Effect": "Allow", "Action": ["s3:GetObject"], "Resource": "arn:aws:s3:::reports/*" }]
}
```

## 見つけ方

- AI レビュー（作業の区切り・コミットの直後）: 分類 `excessive-permission`

## 当てはまらないとき

- 簡易チェック・AI レビューの指摘: その行に `security-kit:allow` と理由を書く
- 印は、利用者が当てはまらないと判断したときだけ付ける。AI が自分の判断で付けてはいけない。印の追加は PR でレビューされる。
- ルールそのものを一時的に外すときは、プロジェクトの `.claude/security-kit.json` に期限つきの例外を書き、PR で承認を受ける。
