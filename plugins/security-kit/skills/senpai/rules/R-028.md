# R-028 GitHub Actions の危ない書き方

| 項目 | 内容 |
|---|---|
| 重大度 | 警告 |
| 領域 | GitHub Actions のワークフロー |
| 根拠 | CWE-78 OS コマンドインジェクション、CWE-829 信頼できない機能の取り込み、OWASP Top 10:2025 A03 ソフトウェアサプライチェーンの不備 |

## 伝え方

- 何が危ないか: ワークフローに、外部から操作できる値の埋め込み、固定していない Action、危ない起動方法のいずれかがある
- なぜ危ないか: issue や PR の題名などからコマンドを仕込まれたり、乗っ取られた Action に秘密情報を盗まれたりする
- どう直すか: 外部から来る値は env を経由して渡す。Action はコミット SHA で固定する。pull_request_target は使わない

## 違反例（指摘される書き方）

`.github/workflows/greet.yml`：issue の題名がそのままコマンドに入る

```yaml
on: issues
jobs:
  greet:
    runs-on: ubuntu-latest
    steps:
      - run: echo "${{ github.event.issue.title }}"
```

`.github/workflows/ci.yml`：版の名前（v4）は付け替えられる

```yaml
on: push
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
```

`.github/workflows/label.yml`

```yaml
on: pull_request_target
jobs:
  label:
    runs-on: ubuntu-latest
    steps:
      - run: echo labeling
```

## 正常例（安全な書き方）

`.github/workflows/greet.yml`：env を経由して渡す

```yaml
on: issues
jobs:
  greet:
    runs-on: ubuntu-latest
    steps:
      - run: echo "$TITLE"
        env:
          TITLE: ${{ github.event.issue.title }}
```

`.github/workflows/ci.yml`：コミット SHA で固定する（SHA は例。実際の値は Action のリリースで確かめる）

```yaml
on: push
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@0123456789abcdef0123456789abcdef01234567 # v4
```

`.github/workflows/label.yml`

```yaml
on: pull_request
jobs:
  label:
    runs-on: ubuntu-latest
    steps:
      - run: echo labeling
```
