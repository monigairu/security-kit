# R-002 .env・鍵ファイル・認証情報ファイルを AI に読ませない

| 項目 | 内容 |
|---|---|
| 重大度 | 止める |
| 領域 | 秘密情報 |
| 根拠 | 要件定義書 11章 R-002、CWE-200 機密情報の露出 |

## 伝え方

- 何が危ないか: .env や鍵ファイルなど、秘密情報の入ったファイルを読もうとしている
- なぜ危ないか: AI に読まれた秘密情報は、会話の記録や外部への送信を通じて漏れるおそれがある
- どう直すか: 秘密情報のファイルは読まず、必要な設定の名前だけを利用者に確かめる

> 設定と運用で守るルールのため、すり抜けテスト（NFR-07）で確かめる

## 見つけ方

- Claude Code の設定で止める: `Read(**/.env)`、`Read(**/.env.*)`、`Read(**/*.pem)`、`Read(**/*.key)`、`Read(~/.ssh/**)`、`Read(~/.aws/**)`
- 運用で守る: サンドボックスで読み取りを制限し、コマンドに秘密情報の環境変数を渡さない（FR-21）

## 当てはまらないとき

- 設定で止めるルールのため、印では外せない。外す必要があるときは、ルールの担当者に相談する。
