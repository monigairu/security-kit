# R-005 患者データ・本番データを AI や外部サービスに渡さない

| 項目 | 内容 |
|---|---|
| 重大度 | 止める |
| 領域 | データ |
| 根拠 | 要件定義書 11章 R-005 |

## 伝え方

- 何が危ないか: 患者データや本番データを読もうとしている
- なぜ危ないか: AI や外部サービスに渡ると、法令上・信頼上の影響が最も大きい
- どう直すか: 開発にはダミーのデータを使う

> 設定と運用で守るルールのため、すり抜けテスト（NFR-07）で確かめる

## 見つけ方

- Claude Code の設定で止める: `Read(**/*.dcm)`
- 運用で守る: 患者データ・本番データを開発機とリポジトリに置かない
- 運用で守る: データ区分のルールに従う（要件定義書 12章）

## 当てはまらないとき

- 設定で止めるルールのため、印では外せない。外す必要があるときは、ルールの担当者に相談する。
