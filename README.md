# security-kit
AI開発セキュリティ支援キット（仮称）

Claude Code などの AI コーディングツールを使った開発で、セキュリティに強い先輩のように「そこ危ないよ」と声をかけ、理由と直し方を伝えるキットです。重大な事故（秘密情報の漏えい、悪性パッケージの導入など）だけはその場で止め、ルールは YAML で一元管理します。

詳しくは [要件定義書](docs/requirements/requirements.md) を参照してください。

## フォルダ構成

フォルダは、最初のファイルを置くときに作ります（空のフォルダは作りません）。

```
security-kit/
├── docs/
│   ├── requirements/   要件定義
│   ├── design/         基本設計・データ設計
│   ├── specs/          詳細仕様（frontend / backend）
│   └── adr/            設計判断の記録（ADR）
├── rules/              チェックルール（YAML）※実装開始時に作成
├── tests/              テスト ※実装開始時に作成
└── .github/            CI・PRテンプレート ※CI導入時に作成
```

`rules/` やソースコードの配置は、基本設計で決まりしだい確定します。
